# agentic-protocol

Общий протокол для передачи задания, отчёта исполнителя и вердикта ревьюера. Версия 0.1.0. Нормативный текст лежит в [`protocol/`](protocol/). Схемы документов — в [`schemas/`](schemas/).

Роли: Cursor выполняет работу и готовит pull request, Perplexity независимо разбирает результат, пользователь решает спорные вопросы. Протокол не подменяет это разрешение автоматическим merge.

## Быстрый старт

```bash
npm ci
npm test
node scripts/generate-adapters.mjs --write --target /path/to/project
node scripts/generate-adapters.mjs --check --target /path/to/project
```

`--source-sha` по умолчанию равен `git rev-parse HEAD` каталога протокола. Повторный `--write` с теми же входными данными не меняет байты адаптеров.

Подключение к проекту, синхронизация закреплённого коммита и модель доверия описаны в [`docs/adoption.md`](docs/adoption.md), [`docs/sync.md`](docs/sync.md) и [`docs/trust-model.md`](docs/trust-model.md).

## Реальные ограничения

- Perplexity не читает `reviewer-context.md` автоматически и не запускается из репозитория. Файл передаёт человек.
- Исполнитель не выставляет себе вердикт. READY действует только для `reviewed_head_sha`, который рассмотрел ревьюер.
- Отсутствие проверки нельзя записывать как PASS и нельзя выводить из того, что соседняя проверка прошла.
- Синхронизация читает новую ревизию протокола как данные и не запускает её скрипты.
- Пока соответствующий pull request не принят в `main`, опубликованная ветка `main` может содержать только начальный README.
- Протокол описывает договорённость и проверяемые документы. Он не мешает исполнителю технически нарушить правила вне этих проверок.
