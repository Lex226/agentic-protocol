# ADR-0001 — Шаблон решения

Статус: Proposed

Этот файл — шаблон, не реальное решение. Для нового решения копировать его в следующий свободный ADR-номер, заполнить собственным контекстом и не удалять шаблон.

## Контекст

Описать проблему, проверенные ограничения и связанные требования/Issues.

## Принятое решение

Описать предложение, альтернативы и основания. Статус Accepted ставится только после явного согласования владельца с датой и evidence.

## Последствия и проверка

Указать последствия, риски, способ проверки и условия пересмотра. Непроверенные свойства выделить отдельно.
