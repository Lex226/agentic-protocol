## Решения

Blob `CHANGELOG.md` на `main` — LF, 2203 байта. CRLF был только в рабочем дереве до правки (`w/crlf`, 2234). Оба файла записаны UTF-8 без BOM, только LF. Критерий «сохранять CRLF в рабочем дереве» в карточку не входил: его заменила проверка индекса.

`awk` нет в PATH. Программа из `.github/workflows/release.yml` выполнена `C:\Program Files\Git\usr\bin\awk.exe` (Git for Windows). Вход — индекс, `git show :CHANGELOG.md`, канал `cmd`, без перекодирования PowerShell. Эквивалент на PowerShell не использовался.

Тег и GitHub Release не создавались. `workflow_dispatch` не запускался. `release.yml` не менялся. Кандидаты conventions-auditor и неблокирующие замечания ревью C13 не правились.
