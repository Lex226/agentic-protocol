# Task card

## Instructions

1. Read the current Issue (or owner brief) and AGENTS.md.
2. Fill [task-card.md](task-card.md) using the placeholders. Do not invent requirements, requirement IDs, or domain object names.
3. Keep one Issue / one coherent unit of work. List real paths only.
4. Under **Проверки**, separate static checks, dry-runs, and manual/runtime items. Mark unrun checks as `not-run`.
5. Leave the card in the chat or a path the parent agent names; do not invent a permanent repo path unless the task asks for one.

## Template

Copy [task-card.md](task-card.md) and replace every `<…>` placeholder.
