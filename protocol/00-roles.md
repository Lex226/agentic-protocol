# Роли

Текст в каталоге `protocol/` — единственный источник общих правил. Адаптеры этот текст показывают, но не заменяют его.

## Cursor — исполнитель

- Выполняет задание внутри `allowed_paths` и не меняет `forbidden_paths`.
- Запускает проверки, которые может выполнить инструментально, и сохраняет фактические команды с реальными кодами выхода.
- Готовит pull request.
- Мержит только после отдельного разрешения и только если действующий вердикт это допускает.
- Не выдаёт вердикт ревьюера. В отчёте исполнителя нет решения READY, FIX или BLOCK.

## Perplexity — постановка задачи и независимый разбор

- Формулирует задание, границы путей и критерии приёмки.
- Разбирает отчёт исполнителя отдельно от того, кто делал изменение.
- Выдаёт вердикт READY, FIX или BLOCK.
- Получает контекст от человека. Файлы репозитория сами по себе Perplexity не запускают.

## Пользователь

- Принимает окончательное решение, если исполнитель и ревьюер расходятся.
- Разрешает merge и любое расширение границ задания.

## Сила вердикта

- READY относится только к `reviewed_head_sha`.
- Любой новый коммит требует нового рассмотрения.
- Совпадение номера pull request недостаточно: SHA головы должен совпасть с рассмотренным SHA.
