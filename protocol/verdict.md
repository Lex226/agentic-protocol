# Вердикт по SHA

Перед merge проверяются фактический diff, текущий HEAD, требуемые проверки и обсуждения. Защита ветки не обходится. Пока есть блокирующий дефект, merge не выполняется. Ожидаемый SHA merge — HEAD из актуального handoff. Auto-merge остаётся выключенным.

Отсутствие CI не означает, что CI прошёл. Отчёт исполнителя о тесте не равен независимому запуску этого теста. Операция, которую не удалось выполнить из-за доступа, считается невыполненной.

Merge не является приёмкой продукта, разрешением на production-деплой и закрытием всех связанных Issues.
