# Приоритет правил

Три класса. Конституция: [конституция github-playbook](https://github.com/Lex226/github-playbook/blob/main/standards/00-constitution.md).

## Guardrails

Конституция и `protocol/`. Без force-push и прямого push в `main`. Merge только проверенного SHA. Cursor не выполняет merge.

Запрет секретов и персональных данных — Guardrails (Правило 11, уровень 1). Потребитель может только ужесточать. Персональные данные потребитель может разрешить только явным исключением в своём AGENTS.md: политика данных и ссылка на решение владельца (Правило 10, явное исключение вместо тихого дрейфа). Без такого исключения персональные данные запрещены. Других ослаблений Guardrails через AGENTS.md нет.

## Процесс

`protocol/` — единственный источник: роли, цикл, handoff, verdict, формат снимка, docs-only. AGENTS.md потребителя ссылается на `protocol/` и перечисляет ужесточения, не пересказывает. Ослабление — только изменением `protocol/` через Issue в agentic-protocol.

## Предмет

AGENTS.md потребителя: политика данных, платформа, стек, что коммитится, стенды. Политика данных этого класса сама по себе не разрешает персональные данные.

## Конфликт классов

Конфликт классов останавливает работу. Запись — в Issue или PR. Решение принимает владелец. Исключение явное и со ссылкой на Правило 11 и Правило 10 конституции.
