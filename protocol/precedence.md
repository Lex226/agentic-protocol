# Приоритет правил

Три класса: Guardrails, Процесс, Предмет. Конституция владельца подключается через AGENTS.md потребителя и только ужесточает; ослабить Guardrails или protocol/ она не может.

## Guardrails

`protocol/` и подключённая конституция владельца (только ужесточения). Без force-push и прямого push в main. Merge только проверенного SHA. Cursor не выполняет merge.

Запрет секретов и персональных данных — Guardrails. Потребитель может только ужесточать. Персональные данные потребитель может разрешить только явным исключением в своём AGENTS.md: политика данных и ссылка на решение владельца (явное исключение вместо тихого дрейфа). Без такого исключения персональные данные запрещены. Других ослаблений Guardrails через AGENTS.md нет.

## Процесс

`protocol/` — единственный источник: роли, цикл, handoff, verdict, формат снимка, docs-only. AGENTS.md потребителя ссылается на `protocol/` и перечисляет ужесточения, не пересказывает. Ослабление — только изменением `protocol/` через Issue в agentic-protocol.

## Предмет

AGENTS.md потребителя: политика данных, платформа, стек, что коммитится, стенды. Политика данных этого класса сама по себе не разрешает персональные данные.

## Конфликт классов

Конфликт классов останавливает работу. Запись — в Issue или PR. Решение принимает владелец. Исключение явное.
