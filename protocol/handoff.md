# Handoff

Без актуального промпта задача не передана на ревью. Промпт содержит полный SHA после последнего успешного push. Мёржить можно только этот SHA.

После каждого исправляющего push выпускается новый промпт. Старый не используется.

В разделе «Запущено» перечисляются только команды, которые были выполнены, и их фактические результаты. Прогон субагента verifier и сверка родителем называются раздельно.

В разделе «Не запущено / вручную» перечисляются пропуски. Отсутствие CI не считается успешным CI.

В теле pull request по умолчанию стоит `Refs #<N>`. `Closes` используется, только если владелец явно согласился закрыть Issue при merge.

Форма промпта задана скиллом `review-handoff`. `<owner>/<repo>` подставляется из репозитория, который ревьюят, в момент выпуска промпта.
