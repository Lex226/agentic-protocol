# Роли

Правило публикации согласованной задачи. В репозитории-источнике оно записано как ADR-0003. Здесь оно записано в этом файле. Текст причин в `scripts/hooks/guard-git.ps1` по-прежнему называет ADR-0003: скрипт перенесён без изменения логики.

## Кто пишет

Во время реализации файлы репозитория правит Cursor. Второй участник не правит те же файлы, пока эта задача активна. Если пишущих двое, работа останавливается.

## Публикация

Для согласованной задачи Cursor выполняет локальные изменения и проверки, делает commit и push рабочей ветки, создаёт или обновляет pull request. Perplexity независимо проверяет опубликованный HEAD и выполняет merge, если блокирующих замечаний нет. Cursor не выполняет merge и не включает auto-merge. Отдельное разрешение владельца на каждый такой commit, push или merge не требуется.

Это разрешение не покрывает production, деплой, платные услуги, изменение доступа, разрушительные операции и смену согласованного объёма.

Владелец сохраняет продуктовые решения, допуск к стендам, согласование требований и действия вне объёма.

Perplexity закрывает Issue (state_reason completed) только по прямому поручению владельца и только после комментария о приёмке со ссылкой на merge commit. Merge ≠ приёмка ≠ закрытие Issue.

Закрытие PR без merge — только по прямому поручению владельца, после комментария с причиной; ветку не удалять.

Cursor накатывает метки только в репозиторий согласованной задачи, через `scripts/labels/apply-labels.ps1`, набор — `standards/labels.json` из `labels.source` на полном SHA `labels.ref` (до манифеста C14 — SHA из Issue/брифа). Только создать отсутствующие и обновить цвет/описание; удаление не входит. Других прав нет.
